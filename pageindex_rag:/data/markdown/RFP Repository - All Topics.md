| 32 | Does your system limit the number of triggered events provided? If so, describe. | The algorithm to fetch videos is a probabilistic algorithm to provide good distribution of alerts over a day, week, and month, and across Alert Types for each vehicle. The algorithm is tuned in the following ways:
Provide more weight to high severity alerts over moderate severity alerts.
Provide a higher sub-quota to certain type of alerts vs. other type of alerts. (This is at daily level.)
Have a daily, weekly, and monthly sub-quota on total number of alerts, across alert types (different for severe and moderate), but allow for certain alert types (for example, High G) to have a separate daily quota of their own. This is usually set to a high number to practically allow for all High G videos to be fetched automatically. This ensures that even if there were several (non-High G) alerts earlier in the day, and all quota for the day was consumed, if there is a High G Alert later in the day, that video can still be fetched.
Fetch each alert video based on a probability to randomize which video is fetched and to provide for a good distribution across the day.  This will ensure alerts represent the whole day and not just the beginning or end of the day. |
